Qt source references and verification status

The Windows package uses the existing Qt 6.5.3 AndroidEmu prebuilt. Its Qt runtime code uses the GPL-2.0-only alternative already offered by Qt. This choice does not change the binaries or replace third-party licenses.

Verified prebuilt provenance

  • Prebuilt repository revision: f2d41b8d15c2a628e95c2e755ed92186d03b763c.
  • Windows import: f6a5499b8ca84998868c7c39cc2d3bdab3ac9fbe, official build 11487595, February 25, 2024.
  • The only change in windows_msvc-x86_64 between the import and the selected prebuilt revision is the addition of BUILD.bazel. The library files are unchanged.
  • The installed SDK module metadata records Qt 6.5.3 and MSVC 19.38.33134.0.

That qtwebengine revision pins its Chromium snapshot, qtwebengine-chromium, at ef090c47d08c734ae2b3c1db508982aca0f3ee1e.

The historical Qt 6.5.3 Python build script lists these eight modules and the AndroidEmu library suffix. It initializes the Qt submodules, configures a shared release build with the win32-msvc platform, and disables PDF, printing, WebRTC and spellchecking. The old build-qt6.sh script targeting Qt 6.2.1 is not the 6.5.3 build entry point.

Retrieve the source superproject at the fixed commit above and initialize its submodules using init-repository as described by the historical build script. Keep all module and Chromium submodule revisions pinned by that checkout. The historical script must be reviewed before execution: it uses C:\qttmp and deletes that directory. These are source references, not a new Kemu build step.

Third-party notices

The Qt third-party notices contain the qt_attribution.json entries of the referenced Qt Base, SVG, Image Formats, Declarative and Positioning sources for components in the shipped Qt libraries. Entries used only on other platforms, by modules that are not shipped or by build tools are omitted. Qt WebChannel and Qt WebSockets have no third-party attributions. The notices select GPLv2 for FreeType and its rasterizer, CC0 for BLAKE2 and MIT for the Vulkan XML specification.

The Qt WebEngine Chromium notices were collected from the pinned qtwebengine-chromium revision using the license file rules of its tools/licenses.py. Without the original build directory, they cover every third-party directory in the snapshot, including components that may not be part of the Windows libraries. See also Qt WebEngine licensing.

Outstanding verification

The historical manifest and build script are evidence of the build approach, but the complete CI manifest for build 11487595 was not available from its public artifact listing during this review. Exact build-script revision, local patches and all build inputs therefore remain unverified. A branch name or version number alone does not establish complete corresponding source.

The included notices were collected from the referenced sources, not from the build output of 11487595. This page does not certify the entire distribution as license-compliant.
