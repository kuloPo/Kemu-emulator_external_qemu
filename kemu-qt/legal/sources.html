Qt runtime source

This package uses the existing AndroidEmu Qt 6.5.3 prebuilt. Its official Windows import was build 11487595. The import record, fixed source references and historical build instructions are listed in Qt source references and verification status.

The exact CI source manifest for that build has not yet been verified. These source references are not a claim that complete corresponding source has already been delivered for the prebuilt.

For the kernel and modules, use the source revisions recorded for the prebuilt commit selected by the release's Android manifest.

Development builds correspond to their build checkout, including local changes. Source for an older release must match that release, rather than a current branch tip.

If source or build information for a release is missing, report the release version and component.

External source links require an internet connection. The license texts and bundled component notices can be read offline.
